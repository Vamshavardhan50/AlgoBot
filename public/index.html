Core Bot Features

Grouped Contest Tracks

Automatically fetches schedules from LeetCode, Codeforces, CodeChef, and AtCoder. Groups starting alerts in a single message to prevent clutter.

Problems of the Day

Daily scrapes from GeeksforGeeks, LeetCode, and Codeforces. Prepend flirty lines generated dynamically via Groq API models.

Codeforces Duels

Challenge server members to solve specific problems within a time limit. Auto-verifies submission status live via Codeforces APIs.

Discord DB Persistence

Persistent SQLite database backups pushed directly to private Discord logs. Never lose configurations or scoreboard stats on Render restarts.
